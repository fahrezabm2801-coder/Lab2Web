Proyek Mini — Form Biodata MahasiswaProject Mini
Penjelasan:

Pertama, kita membuat bagian atas halaman menggunakan <header> yang berisi judul Biodata Mahasiswa. Setelah itu kita membuat menu navigasi menggunakan <nav>, lalu memasukkan beberapa link seperti Beranda,Biodata, dan Form. Link Biodata dan Form menggunakan tanda # yang mengarah ke bagian halaman berdasarkan id yang sudah dibuat.

Setelah bagian navigasi selesai, kita membuat <main> sebagai isi utama halaman. Di dalamnya kita membuat section pertama dengan id="biodata" untuk menampilkan Data Mahasiswa. Kemudian dibuat tabel menggunakan <table>, <tr>, <th>, dan <td> untuk menampilkan NIM, nama, serta program studi. Setelah itu kita membuat section kedua dengan id="form" yang berisi Form Biodata.

Terakhir, kita membuat form untuk memasukkan nama, email, program studi, dan alamat. Untuk program studi digunakan <select> agar pengguna dapat memilih pilihan yang tersedia, sedangkan alamat menggunakan <textarea> agar bisa menulis teks lebih panjang. Setiap input diberi required supaya wajib diisi, kemudian disediakan tombol Simpan untuk mengirim form dan Reset untuk mengosongkan kembali isian. Setelah seluruh bagian selesai, kita menambahkan <footer> sebagai bagian paling bawah halaman yang berisi informasi hak cipta tahun 2026.
